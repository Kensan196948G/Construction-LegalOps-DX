# ADR 0003 — 監査ログを SHA-256 ハッシュチェーンで保護する

- 状態: Accepted
- 決定日: 2026-06-10

## コンテキスト

監査対応（ISO/J-SOX 相当）では、操作履歴の改ざん検知と完全性の証跡が求められる。
DB 行の更新だけでは管理者による遡及改ざんを防げない。

## 決定

- 監査ログ行ごとに `hash_chain` を持ち、前行ハッシュ + 行内容の SHA-256 を連鎖させる。
- 改ざん検証 API と CSV エクスポート（WORM 相当の外部出力）を提供する。
- Sentinel 等への転送は外部承認後に有効化する。

## 結果

- 監査ログの改ざん検知が可能となり、法定保存期間（建設業法 5 年 / 電帳法 7 年）方針と整合した。
