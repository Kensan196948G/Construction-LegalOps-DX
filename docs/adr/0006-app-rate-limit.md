# ADR 0006 — アプリ層レート制限を ASGI ミドルウェアで実装する

- 状態: Accepted
- 決定日: 2026-08-12

## コンテキスト

nginx の `limit_req` はリバースプロキシ経由のアクセスにのみ有効で、バックエンド直接アクセス時には
総当たり攻撃への保護が存在しなかった。外部評価でも「アプリ層レート制限不在」が指摘されている。

## 決定

- 純 ASGI のスライディングウィンドウ式レート制限ミドルウェアを実装し、全 `/api/v1` リクエストに適用する。
- 認証系（`/api/v1/auth`・`/api/auth`）は厳しい上限（既定 60 回/分）、一般 API は 600 回/分（既定）。
- ヘルス・メトリクス・ドキュメント系は除外する。設定値は環境変数で変更可能とする。
- 多レプリカ構成では Redis 共有カウンタへの移行を運用バックログとする。

## 結果

- バックエンド直接アクセス時の総当たり保護が成立し、nginx との多層防御となる。
- 429 応答は `Retry-After` 付きで返し、クライアントに再試行待ちを伝える。
