# ADR 0004 — PostgreSQL RLS + 案件単位 ACL でデータ境界を実装する

- 状態: Accepted
- 決定日: 2026-07-20

## コンテキスト

部署単位閲覧制限・外部顧問弁護士のゲストアクセス・倫理壁（M&A・訴訟等）を、アプリ層のロジックだけで
保証すると、実装漏れや将来の経路追加で権限逸脱が発生するリスクがある。

## 決定

- PostgreSQL RLS を 13 テーブルに適用し、DB 層で行単位の可視性を強制する。
- 案件単位 ACL（`case_access`）と倫理壁フラグを組み合わせ、例外的アクセスを明示管理する。
- アプリ層でも RBAC（7 ロール）+ 部署フィルタを併用する多層構成とする。

## 結果

- 権限逸脱の影響範囲を DB 層で制限でき、監査・レビューの対象が明確になった。
