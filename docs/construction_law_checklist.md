# 建設関連法令チェックリスト (Construction Law Checklist)

本書は契約レビュー・社内コンプライアンス点検に用いる条文単位チェックリストである。AI は条文との照合を補助し、最終判断は法務担当者・顧問弁護士が行う。公共工事 8 割／民間 2 割の業態に応じ、入札・談合・贈収賄・施工体制台帳まで網羅する。

---

## 1. 建設業法

### 1.1 許可・営業所
- [ ] 自社・相手方の建設業許可（業種別、特定／一般）が有効期限内か。
- [ ] 専任技術者の配置要件（建設業法 26 条）と整合するか。
- [ ] 営業所ごとの専任技術者要件。
- [ ] 経営事項審査の最新結果と整合するか。

### 1.2 契約書面（19 条）
- [ ] 工事内容、請負代金、工期、引渡時期。
- [ ] 前金払・部分払・出来高払。
- [ ] 設計変更時の取扱、第三者損害負担。
- [ ] 天災等不可抗力時の損害負担。
- [ ] 価格等変動による請負代金変更（スライド）。
- [ ] 契約不適合責任、紛争解決方法。
- [ ] 工事着工前に書面交付がなされているか。

### 1.3 一括下請負禁止（22 条）
- [ ] 一括下請負に該当しないか。
- [ ] 公共工事は事前承諾を得ても全面禁止である点を遵守。
- [ ] 民間工事で書面承諾を得ている場合の文書整備。

### 1.4 下請代金支払（24 条の 3 〜 6）
- [ ] 支払期日は引渡し申出から 50 日以内。
- [ ] 特定建設業者は 50 日以内、できる限り短く。
- [ ] 出来高検査の遅延禁止。

### 1.5 施工体制台帳・施工体系図（24 条の 8）
- [ ] 公共工事で下請契約締結時に作成。
- [ ] 再下請通知書を全下請から徴収。
- [ ] 現場に掲示。

### 1.6 標識掲示・帳簿
- [ ] 営業所・現場の標識掲示。
- [ ] 営業所ごとの帳簿備付け（10 年保存）。

### 1.7 技術者制度
- [ ] 公共工事における監理技術者・主任技術者の専任配置。
- [ ] 監理技術者補佐の活用可否。
- [ ] 一定金額（4,500 万円・建築一式 7,000 万円等）以上の専任要件。

## 2. 下請法（下請代金支払遅延等防止法）

### 2.1 適用判定
- [ ] 親事業者・下請事業者の資本金区分（製造委託、修理委託、情報成果物作成委託、役務提供委託）。
- [ ] 建設業の請負契約は建設業法優先、ただし役務委託・情報成果物委託は下請法適用余地あり。

### 2.2 3 条書面
- [ ] 給付内容、給付期日、給付場所、検査期日、支払期日、支払方法、金額、知的財産権の取扱。
- [ ] 発注後直ちに交付。

### 2.3 禁止事項（4 条）
- [ ] 受領拒否、下請代金の支払遅延、減額、返品、買いたたき。
- [ ] 物の購入強制・役務利用強制。
- [ ] 報復措置、有償支給材料の早期決済、不当な経済上の利益提供要請。
- [ ] 不当な給付内容変更・やり直し。

### 2.4 支払期日・遅延利息
- [ ] 給付受領後 60 日以内。
- [ ] 遅延利息年 14.6%。
- [ ] 手形交付の場合は割引困難な手形交付禁止。

### 2.5 5 条書類
- [ ] 取引記録の作成・2 年間保存。

## 3. 労働安全衛生法 / 労働基準法

### 3.1 安全衛生管理体制
- [ ] 元方事業者としての統括安全衛生管理体制（労安法 15 条）。
- [ ] 安全衛生協議組織、作業間連絡調整。
- [ ] 元請の指導義務（労安法 29 条）。

### 3.2 元請責任
- [ ] 工事現場の安全衛生計画策定、リスクアセスメント。
- [ ] 新規入場者教育、KY 活動。
- [ ] 重機・墜落・酸欠・電気等のリスク特有対策。

### 3.3 労働時間・割増
- [ ] 建設業の時間外労働上限規制（2024 年 4 月適用、月 45 時間／年 360 時間原則）。
- [ ] 36 協定特別条項。
- [ ] 週休 2 日制への対応、工期設定への反映。

### 3.4 一人親方・偽装請負
- [ ] 実態が雇用に近い場合の偽装請負リスク。
- [ ] 一人親方労災特別加入の確認。

### 3.5 社会保険加入
- [ ] 健康保険・厚生年金・雇用保険の加入状況。
- [ ] CCUS (建設キャリアアップシステム) 登録状況。

## 4. 個人情報保護法

### 4.1 取得・利用
- [ ] 利用目的の特定・通知・公表。
- [ ] 要配慮個人情報の同意取得。

### 4.2 第三者提供
- [ ] 同意取得 / オプトアウト届出 / 委託 / 共同利用の区分。
- [ ] 第三者提供記録の作成・保存。

### 4.3 委託先管理
- [ ] 委託契約に安全管理措置・再委託承諾・監査権を含む。

### 4.4 越境移転
- [ ] 外国にある第三者への提供時の同意・基準適合体制。

### 4.5 漏洩等報告
- [ ] 漏洩等発生時の 個人情報保護委員会への速やかな報告・本人通知。

### 4.6 安全管理措置
- [ ] 組織的・人的・物理的・技術的・外的環境の把握。

### 4.7 マイナンバー（番号法）
- [ ] 取得目的の限定列挙。
- [ ] 厳格な安全管理措置。
- [ ] 委託時の監督義務。
- [ ] 不必要な複写の禁止、廃棄記録。

---

## 5. 電子帳簿保存法

### 5.1 電子取引（7 条）
- [ ] 電子で受け取った請求書・領収書・契約書は電子のまま保存。
- [ ] 改ざん防止措置（タイムスタンプ／訂正削除履歴／規程整備）。
- [ ] 検索要件（日付・取引先・金額）。
- [ ] 保存期間 7 年（欠損金等 10 年）。

### 5.2 スキャナ保存
- [ ] スキャン解像度、タイムスタンプ、入力者情報。

### 5.3 国税関係帳簿書類の電子保存
- [ ] 訂正削除履歴、相互関連性、見読可能性、検索性、システム関係書類備付け。

## 6. インボイス制度（適格請求書等保存方式）

- [ ] 自社・相手方の適格請求書発行事業者登録番号確認。
- [ ] 請求書記載事項（登録番号、適用税率、税率ごとの消費税額等）。
- [ ] 免税事業者からの仕入に対する経過措置（80% / 50% / 0%）の正しい運用。
- [ ] 一人親方・個人事業主との取引における事前合意（免税事業者であることを理由とした一方的減額の禁止：独禁法・下請法）。
- [ ] 電子インボイス（Peppol 等）対応方針。

---

## 7. 反社会的勢力排除

- [ ] 反社条項（表明保証、解除権、損害賠償、無催告解除）の完備。
- [ ] 取引開始前の反社チェック（自社 DB、外部 DB、公知情報）。
- [ ] 関係者（役員、株主、実質支配者）への適用範囲。
- [ ] 各都道府県暴力団排除条例への適合。
- [ ] 該当判明時の対応フロー（取引解除、警察協議、顧問弁護士関与）。

---

## 8. 贈収賄・腐敗防止

### 8.1 国内
- [ ] 刑法 198 条（贈賄罪）、公務員等への利益供与禁止。
- [ ] 公共発注者・自治体職員への過剰接待・贈答禁止。
- [ ] 自治体倫理条例の確認。

### 8.2 海外要素
- [ ] 不正競争防止法 18 条（外国公務員贈賄罪）。
- [ ] FCPA、UK Bribery Act 該当性。

### 8.3 社内ルール
- [ ] 接待・贈答事前申請（上限額：相手方ごと 1 万円超は要申請等社内基準）。
- [ ] ファシリテーション・ペイメント禁止。
- [ ] 第三者（コンサル、エージェント）経由の利益供与禁止。

---

## 9. 談合・独占禁止法

- [ ] 公共工事の入札談合への不関与（独禁法 3 条、入札談合等関与行為防止法）。
- [ ] 競合他社との接触記録（業界団体会合の議題・参加者・配布資料）。
- [ ] 内部通報制度（公益通報者保護法）の周知。
- [ ] リニエンシー（課徴金減免）申請判断フロー。
- [ ] 民間談合（受注調整）も同様に禁止。

---

## 10. 入札規程・公共調達

### 10.1 入札参加資格
- [ ] 経営事項審査（経審）の最新点数。
- [ ] 自治体・国の競争参加資格申請。
- [ ] 指名停止情報（自社）、相手方の指名停止状況。

### 10.2 入札手続
- [ ] 一般競争 / 指名競争 / 随意契約の区分。
- [ ] 総合評価方式の技術提案・施工計画。
- [ ] 低入札価格調査基準価格・最低制限価格。
- [ ] 公契連モデルへの適合。

### 10.3 落札後手続
- [ ] 契約締結期限（落札後 7 日以内等）。
- [ ] 契約保証金（10% 等）または履行保証保険。
- [ ] 前払金、中間前払金、出来高部分払。

### 10.4 公共工事品確法・入契法
- [ ] 適正な予定価格、ダンピング受注の禁止。
- [ ] 施工体制の適正化（一括下請禁止、施工体制台帳）。
- [ ] 賃金水準確保（公契条例該当自治体）。

## 12. AI 補助の限界

- 各条文の最新改正状況は法務担当者が一次情報（e-Gov）で確認する。
- AI は条文番号・キーワードの照合は得意だが、解釈・運用の幅は人間判断。
- 自治体条例（暴排・公契・倫理）は地域差が大きく、地場法律事務所への確認を推奨。
