# リスクスコアリング方針 (Risk Scoring Policy)

本書は契約案件のリスク自動評価ロジック・運用基準を定める。AI は補助的にスコアを算出し、法務担当者が最終判定を行う。日本の建設土木業の公共工事 8 割／民間 2 割の比率を踏まえ、公共発注特有のリスク（指名停止・談合・贈収賄・入札・施工体制台帳不備）も加点項目とする。

---

## 1. 目的

1. 契約レビュー優先順位の客観化。
2. 承認ルート自動振分け（`approval_workflow_policy.md` と連動）。
3. 顧問弁護士エスカレーション要否の判定。
4. 経年での社内案件リスク傾向分析。

---

## 2. スコアモデル概要

- スコアレンジ: 0〜100 点（高いほどリスク大）。
- 加点項目（リスク要因）と減点項目（軽減要因）を合算。
- 種別ごとのベーススコア + 条項検出による加減点 + 当事者・金額補正。

### 2.1 ランク区分

| ランク | スコア | 対応 |
|--------|--------|------|
| 低 (Low) | 0〜29 | 法務担当 1 名で承認可、SLA 1 営業日 |
| 中 (Medium) | 30〜59 | 法務担当 + 課長確認、SLA 2 営業日 |
| 高 (High) | 60〜79 | 法務課長＋管理本部長承認、SLA 3 営業日 |
| 最高 (Critical) | 80〜100 | 顧問弁護士フラグ自動付与、役員報告 |

---

## 3. ベーススコア（契約種別）

| 契約種別 | ベース |
|----------|--------|
| 工事請負契約（公共） | 25 |
| 工事請負契約（民間・大口） | 25 |
| 工事請負契約（民間・小口） | 15 |
| 下請契約 | 20 |
| 業務委託契約 | 15 |
| NDA | 5 |
| 覚書 (MOU) | 10 |
| 発注書・注文書 | 5 |
| JV 協定書 | 30 |
| 変更契約書 | 原契約ベース + 5 |
| その他 | 10 |

---

## 4. 加点項目（リスク増要因）

### 4.1 損害賠償・責任関連

| 項目 | 加点 |
|------|------|
| 損害賠償上限の定めなし | +20 |
| 損害賠償上限が契約金額の 100% 超 | +10 |
| 間接損害・逸失利益も賠償対象 | +15 |
| 懲罰的損害賠償の規定 | +20 |
| 連帯保証・連帯責任の引受 | +10 |
| 弁護士費用全額相手方負担 | +5 |

### 4.2 業務範囲・履行関連

| 項目 | 加点 |
|------|------|
| 業務範囲が曖昧（「協議のうえ別途」多用 3 箇所以上） | +10 |
| 一括下請負禁止（建設業法 22 条）抵触懸念 | +15 |
| 再委託無制限（事前承諾不要） | +15 |
| 成果物の検収基準が不明確 | +10 |
| 履行期日が「相手方の要請する日」など他律的 | +10 |

### 4.3 契約不適合責任・瑕疵

| 項目 | 加点 |
|------|------|
| 契約不適合責任期間が 5 年超（建設一般工事） | +10 |
| 契約不適合責任期間が 10 年超（構造耐力上主要を除く） | +20 |
| 完全責任型（過失の有無問わず） | +10 |
| 損害拡大防止義務が片務 | +5 |

### 4.4 解除・終了関連

| 項目 | 加点 |
|------|------|
| 相手方からの無催告解除権 | +15 |
| 自社からの解除権制限（事由限定列挙 5 個以下） | +10 |
| 違約金が契約金額の 30% 超 | +15 |
| 自動更新（オプトアウト期間 90 日超） | +5 |

### 4.5 知的財産・データ

| 項目 | 加点 |
|------|------|
| 自社作成成果物の著作権全部譲渡 | +5 |
| 著作者人格権不行使特約なし | +5 |
| 個人情報を取扱うが第三者提供同意条項なし | +10 |
| マイナンバーを取扱う | +15 |

### 4.6 公共工事・コンプライアンス

| 項目 | 加点 |
|------|------|
| 公共工事かつ JV 案件 | +10 |
| 入札参加資格に直接影響する内容 | +15 |
| 反社条項の欠落・不十分 | +20 |
| 贈収賄・FCPA・UK Bribery Act 表明保証なし（海外要素あり時） | +15 |
| 談合関連の表明保証なし（公共工事） | +10 |
| 経営事項審査に影響する完工高変動 | +5 |
| 施工体制台帳不備の懸念 | +10 |

### 4.7 当事者属性

| 項目 | 加点 |
|------|------|
| 新規取引先（過去 36 ヶ月取引なし） | +5 |
| 信用情報に懸念（与信スコア要確認） | +10 |
| 反社チェック未済または該当懸念 | +20 |
| 海外法人（外国準拠法・外国管轄） | +15 |
| 当事者が個人事業主・一人親方 | +5 |

### 4.8 金額補正

| 金額 | 加点 |
|------|------|
| 1,000 万円未満 | +0 |
| 1,000 万 〜 5,000 万円 | +5 |
| 5,000 万 〜 1 億円 | +10 |
| 1 億 〜 5 億円 | +15 |
| 5 億円超 | +20 |

### 4.9 期間補正

| 期間 | 加点 |
|------|------|
| 3 ヶ月以内 | +0 |
| 〜 1 年 | +3 |
| 〜 3 年 | +5 |
| 〜 5 年 | +8 |
| 5 年超 / 無期限 | +12 |

---

## 5. 減点項目（リスク軽減要因）

| 項目 | 減点 |
|------|------|
| 自社雛形をそのまま採用（修正なし） | -10 |
| 公共工事標準請負契約約款に準拠 | -10 |
| 民間連合協定工事請負契約約款に準拠 | -8 |
| 顧問弁護士事前確認済み | -10 |
| 既存取引先（過去 36 ヶ月で 10 件以上取引） | -5 |
| 損害賠償上限が契約金額の 30% 以下 | -5 |
| 反社条項・コンプライアンス条項完備 | -3 |
| 個人情報・マイナンバー取扱なし | -3 |
| 紛争解決が自社本店所在地管轄 | -3 |
| 不可抗力条項が明確（地震・パンデミック含む） | -3 |
| 電子契約 + タイムスタンプ + 電子署名法適合 | -3 |

## 6. スコア算定例

### 例 1: 公共工事元請（5,000 万円、新規発注者は無し）
- ベース（工事請負・公共）: 25
- 金額補正（5,000 万円超未満）: +5
- 期間補正（10 ヶ月）: +3
- 標準約款準拠: -10
- 反社条項完備: -3
- 合計: **20 点 → 低リスク**

### 例 2: 下請契約（新規業者、損害賠償上限なし、再委託自由、6,000 万円）
- ベース（下請）: 20
- 損害賠償上限なし: +20
- 再委託無制限: +15
- 新規取引先: +5
- 金額補正: +10
- 合計: **70 点 → 高リスク**

### 例 3: 海外コンサル NDA（米国法準拠、無期限秘密保持）
- ベース（NDA）: 5
- 海外法人: +15
- 無期限秘密保持: +5
- 合計: **25 点 → 低〜中の境界。法務判断で中ランク扱い可**

## 7. オーバーライド（人手調整）

- 法務担当者は AI スコアを ±20 点の範囲で調整可。±20 超は課長承認必須。
- オーバーライド時は必ず理由コードを入力（下表）。
- 監査ログに記録（`audit_log_policy.md`）。

| 理由コード | 内容 |
|------------|------|
| OR-001 | 案件特殊事情（災害復旧等） |
| OR-002 | 顧問弁護士確認済み |
| OR-003 | 過去類似案件との整合 |
| OR-004 | 戦略的判断（受注必要性） |
| OR-005 | その他（自由記述必須） |

---

## 8. モデルの更新

- 四半期に 1 回、法務課で重み係数の見直し会議。
- 重大事例（係争・行政指導）発生時は即時見直し。
- バージョン履歴を本システムに保管し、過去案件は採点時バージョンを保持。

---

## 9. AI 補助の限界

- AI は条項文面からの加減点を行うが、当事者間の力関係・業界慣行・取引履歴を完全に反映できない。
- スコアは「優先順位付け」のためであり、「合意可否の判定」ではない。
- 重大案件は必ず人手レビューを優先する。
